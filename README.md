# LedBar

Приложение в строке меню macOS для управления тремя LED-лентами через MQTT. Поддерживает индивидуальную и общую яркость от 0 до 12, обновление шкал по входящим сообщениям и быстрые команды с разными значениями для нескольких топиков.

## Запуск

Нужны macOS 14 или новее и Xcode Command Line Tools. Откройте `Launch.command` или запустите его в Терминале.

```sh
./Launch.command
```

Сборка появится в `build/LedBar.app`. После запуска откройте LedBar в строке меню и укажите брокер и топики в настройках. LedBar хранит настройки на Mac, а пароль — в Keychain.

Если ваш брокер поддерживает EMQX Delayed Publish, включите **Отложенная публикация EMQX** в настройках MQTT и сохраните подключение. Правый клик по быстрой команде запланирует её на пять минут. Зелёная рамка означает, что брокер принял сообщения.
